# Hey, I'm Kushagra 👋

### AI Engineer · Full-Stack Developer · Creative Technologist

I'm a developer focused on building **intelligent, scalable, and beautifully designed digital products**. I work at the intersection of **Artificial Intelligence, Generative AI, full-stack web development, frontend engineering, and product design**, with a strong interest in turning ambitious ideas into products people actually enjoy using.

My approach sits somewhere between **engineering and design**. I care about what happens behind the interface just as much as what happens inside it - from designing the architecture and building APIs to integrating AI models, structuring databases, optimizing performance, and creating interfaces that feel intuitive, responsive, and polished.

I'm particularly interested in **AI engineering and the future of AI-powered software**. I enjoy experimenting with **LLMs, AI agents, intelligent automation, machine learning, and AI-native applications**, while exploring how these technologies can be combined with modern web technologies to create genuinely useful products.

On the development side, I primarily work with technologies such as **Python, JavaScript, TypeScript, React, Next.js, Node.js, FastAPI, Supabase, and cloud platforms**. I enjoy building everything from interactive frontend experiences and full-stack applications to AI-powered tools and systems that connect complex backend logic with simple user experiences.

But I don't believe great software is only about functionality.

**Good software works. Great software feels right.**

That's why I spend a lot of time thinking about **UI/UX, visual hierarchy, interaction design, typography, motion, accessibility, and the small details** that make a product feel complete. I enjoy combining engineering with tools like **Figma, Framer, Adobe Creative Cloud, and Blender** to create experiences that are technically strong and visually distinctive.

I'm constantly learning, experimenting, and building - whether that's exploring a new AI framework, designing a new interface, building a full-stack product from scratch, or simply taking an idea and seeing how far I can push it.
